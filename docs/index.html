ElevateAI

AI-Powered Interview Preparation Platform — Flask application

What this repo contains

This repository is a Flask web application (server-side Python). It includes app.py, a templates/ folder and a static/ folder. GitHub Pages only serves static sites — it cannot run a Python server.

Run locally

To run the app locally:

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py

Then open http://127.0.0.1:5000 in your browser.

Host it online

Since this is a Flask app, choose a platform that runs Python servers (examples):

  • Render — easy GitHub + free tier
  • Heroku — add a Procfile (e.g. web: gunicorn app:app) and push
  • Railway, Fly, DigitalOcean App Platform, or an EC2 droplet
